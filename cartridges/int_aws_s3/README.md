# int_aws_s3

## Purpose

`int_aws_s3` gives Venny I/O a reusable object-storage adapter for Amazon S3 without coupling application cartridges directly to the AWS SDK for PHP. It exposes object upload, download, metadata lookup, existence checks, copy, move, delete, object listing, and presigned GET/PUT URL generation through a consistent vanilla-PHP interface. The cartridge is responsible for AWS authentication, S3 request construction, provider error translation, key-prefix handling, and safe diagnostics. It does not own Venny's file records, media records, attachment records, business objects, or bucket lifecycle. Those remain with the Venny cartridge that owns the corresponding application domain.

## Provider

## Installation

This cartridge uses vanilla PHP with Composer and AWS SDK for PHP v3.

From the cartridge directory:

```bash
composer install
```

Or from the parent Venny I/O project:

```bash
composer require aws/aws-sdk-php:^3.0
composer dump-autoload
```

Venny I/O requires PHP 8.1 or newer for this cartridge.

## Configuration

### `v_AWS_ACCESS_KEY_ID`

Optional when AWS credentials are supplied through another AWS SDK credential provider.

Static AWS access-key identifier.

Do not expose in Business Manager output.

### `v_AWS_SECRET_ACCESS_KEY`

Optional when AWS credentials are supplied through another AWS SDK credential provider.

Static AWS secret access key.

This is secret.

### `v_AWS_SESSION_TOKEN`

Optional.

Temporary-session token when using temporary AWS credentials.

This is secret.

### `v_AWS_REGION`

Required.

AWS region for the configured S3 bucket.

Example:

```text
us-east-1
```

### `v_AWS_S3_BUCKET`

Required.

The S3 bucket used by this cartridge.

Example:

```text
venny-production-assets
```

### `v_AWS_S3_PREFIX`

Optional.

A path prefix automatically prepended to all object keys generated by this cartridge.

Example:

```text
uploads/
```

The prefix lets one bucket safely host multiple Venny applications or storage domains without requiring every caller to duplicate path logic.

### `v_AWS_S3_ENDPOINT`

Optional.

Custom S3-compatible endpoint override.

Leave unset for normal AWS S3.

### `v_AWS_S3_PATH_STYLE`

Optional.

Boolean controlling path-style endpoint behavior where required by a compatible endpoint.

Default:

```text
false
```

## Capabilities

### Put Object

```php
put(string $key, string|resource $body, array $options = [])
```

Uploads object data using S3 `PutObject`.

Supported options are passed through conservatively for documented S3 fields such as:

```text
ContentType
CacheControl
ContentDisposition
ContentEncoding
Metadata
ACL
StorageClass
ServerSideEncryption
SSEKMSKeyId
Tagging
```

Application cartridges should avoid ACL-based public access unless their architecture explicitly requires it.

### Put File

```php
putFile(string $key, string $filePath, array $options = [])
```

Uploads a local file.

The AWS SDK may manage multipart behavior internally for appropriate higher-level upload workflows, but this cartridge does not expose low-level multipart state as Venny application state.

### Get Object

```php
get(string $key, array $options = [])
```

Retrieves an S3 object and returns body, content type, content length, ETag, last-modified information, metadata, and provider response details when available.

### Head / Metadata

```php
head(string $key)
```

Uses S3 `HeadObject` to retrieve metadata without downloading the object body.

### Exists

```php
exists(string $key)
```

Performs a non-mutating existence check.

### Delete

```php
delete(string $key)
```

Deletes the configured object.

### Copy

```php
copy(string $sourceKey, string $destinationKey, array $options = [])
```

Copies an object inside the configured bucket.

### Move

```php
move(string $sourceKey, string $destinationKey, array $options = [])
```

Copies the object and deletes the source only after the copy succeeds.

### List Objects

```php
list(string $prefix = '', int $maxKeys = 1000, ?string $continuationToken = null)
```

Returns objects within the configured bucket and cartridge prefix using S3 `ListObjectsV2`.

### Presigned GET URL

```php
createPresignedGetUrl(string $key, string $expires = '+15 minutes', array $options = [])
```

Generates a time-limited GET URL without exposing AWS credentials.

### Presigned PUT URL

```php
createPresignedPutUrl(string $key, string $expires = '+15 minutes', array $options = [])
```

Generates a time-limited direct-upload PUT URL.

Callers must preserve any signed headers when using the resulting URL.

## Usage

```php
<?php

require __DIR__ . '/vendor/autoload.php';

use Venny\Cartridges\AwsS3\Config;
use Venny\Cartridges\AwsS3\Provider;

$provider = new Provider(Config::fromEnvironment());

$result = $provider->put(
    'images/example.jpg',
    file_get_contents('/tmp/example.jpg'),
    [
        'ContentType' => 'image/jpeg',
        'CacheControl' => 'public, max-age=31536000'
    ]
);

echo $result->providerId();
```

Retrieve:

```php
$result = $provider->get('images/example.jpg');

$body = $result->data()['body'];
```

Presigned download:

```php
$url = $provider
    ->createPresignedGetUrl('documents/report.pdf', '+20 minutes')
    ->data()['url'];
```

Presigned upload:

```php
$url = $provider
    ->createPresignedPutUrl(
        'uploads/new-photo.jpg',
        '+10 minutes',
        ['ContentType' => 'image/jpeg']
    )
    ->data()['url'];
```

## Key Prefixing

If:

```text
v_AWS_S3_PREFIX=uploads/
```

then:

```text
avatars/al.png
```

is stored as:

```text
uploads/avatars/al.png
```

Callers work with logical keys and do not need to prepend the configured prefix themselves.

## Error Handling

The cartridge translates AWS SDK failures into Venny-specific exceptions:

```text
ConfigurationException
AuthenticationException
NotFoundException
ProviderException
ValidationException
```

Provider exceptions preserve useful AWS context when available:

```text
AWS error code
AWS error type
AWS request ID
AWS status code
AWS service
```

AWS credentials and session tokens are never returned.

## Provider Results

Normalized operations return `ProviderResult`.

Example:

```php
[
    'success' => true,
    'provider' => 'aws',
    'tool' => 's3',
    'operation' => 'put',
    'provider_id' => 'images/example.jpg',
    'data' => [
        'key' => 'images/example.jpg',
        'etag' => '...'
    ],
    'metadata' => [
        'bucket' => 'venny-production-assets'
    ]
]
```

## Health Check

The health check performs non-destructive diagnostics.

It validates:

```text
configuration
S3 client construction
bucket accessibility
configured prefix
credential resolution
```

The health check uses `HeadBucket`.

It does not create, upload, overwrite, copy, or delete an object.


```text
bm/configuration.php
```

Health diagnostics:

```text
bm/health.php
```

Business Manager must never display raw AWS secret access keys or session tokens.

## Persistence

This cartridge owns no PostgreSQL tables.

Venny file metadata, attachment relationships, media records, ownership, retention policy, and business-domain state should remain in the cartridge that owns those concepts.

## Security

Use IAM policies with the narrowest permissions required by the application.

Prefer private buckets and presigned access rather than making buckets or objects public by default.

Never log:

```text
AWS secret access keys
session tokens
Authorization headers
presigned URLs after their operational use if logs are broadly accessible
```
